## 🛠️ Notificación de Incidencias y Errores (GitHub Issues)

Para informar sobre un error comprobado (Bug) o solicitar una mejora técnica:

1. Visite la sección [GitHub Issues](https://github.com/sotium/sotium-pos/issues).
2. Verifique mediante el buscador que la incidencia no haya sido reportada previamente.
3. Si es un nuevo error, complete la plantilla de Bug Report proporcionando:
   - Versión exacta de Sotium POS y Node.js.
   - Entorno (OS, navegador, base de datos local o PostgreSQL).
   - Pasos exactos para reproducir el fallo.
   - Logs del servidor (`winston`) y de la consola del navegador.
